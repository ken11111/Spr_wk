## 1. システム構成と制御工学モデルの対応関係

### 1.1 Phase 8 アーキテクチャの制御工学的解釈

**実システム構成:**
```
Camera → [TCP Reader] → Queue1 → [JPEG Decoder] → Queue2 → [GUI Thread] → Display
  u(t)        G₁(s)      q₁(t)        G₂(s)        q₂(t)       G₃(s)      y(t)
```

**制御工学モデル:**
```
G₁(s) = K₁/(τ₁s + 1)  [キュー制御系: K₁=1.0, τ₁=33ms]
G₂(s) = K₂·e^(-θs)/(τ₂s + 1)  [TCP制御系: K₂=0.85, τ₂=134ms, θ=25ms]
L(s) = G₁(s) × G₂(s)  [開ループ伝達関数]
T(s) = L(s)/(1+L(s))  [閉ループ伝達関数]
```

### 1.2 実装パラメータと制御理論パラメータの対応

| 実装パラメータ | 制御理論 | 値 | 物理的意味 | 改善方針 |
|------------|----------|----|-----------|---------|
| **TCP読取り平均時間** | τ₂ = 134ms | 0.134s | TCP制御系時定数 | ネットワーク最適化 |
| **キュー処理ゲイン** | K₁ = 1.0 | 1.0 | キュー制御利得 | バッファサイズ調整 |
| **TCP通信遅延** | θ = 25ms | 0.025s | 通信むだ時間 | プロトコル改善 |
| **JPEG処理効率** | K₂ = 0.85 | 0.85 | TCP制御利得 | アルゴリズム最適化 |
| **キュー応答時間** | τ₁ = 33ms | 0.033s | キュー時定数 | メモリ最適化 |

### 1.3 状態方程式による動的解析

**キュー深度の状態方程式:**
```
dq₁(t)/dt = u₁(t) - y₁(t)  [TCP Reader → JPEG Decoder]
dq₂(t)/dt = y₁(t) - y₂(t)  [JPEG Decoder → GUI Thread]

where:
u₁(t): Camera入力 (30fps想定)
y₁(t): JPEG Decoder出力
y₂(t): GUI Thread出力
```

**Phase別定常状態解析:**
- **Phase 7.3.3**: q₁ = 6.5 (過負荷状態)
