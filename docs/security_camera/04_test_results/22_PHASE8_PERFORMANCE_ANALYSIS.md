- エラー: `Connection closed (need 56788 bytes, have 21960)`
- 原因: GS2200M WiFiモジュールの内部バッファ枯渇
- 詳細: `21_PHASE8_TCP_DISCONNECT_ANALYSIS.md`参照

### 4.2 TCP最大送信時間の増加

| 項目 | 前回 | 今回 |

| TCP最大送信時間 | 1,939 ms | 2,713 ms |

バースト時の遅延が増加。GS2200Mの限界に近い運用状態。

依然として53.7%のフレームがドロップ。GS2200Mの帯域制限による根本的な制約。
